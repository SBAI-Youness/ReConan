The Platform

Modular Architecture

Built with a strictly decoupled layered architecture separating the UI (JavaFX), Application logic, and Data layers.

Local-First Data

Powered by SQL Server to store targets, entities, and logs locally, keeping your investigation data secure and private.

Enterprise Ready

Utilizes robust technologies like JDBC, Jackson, and JGraphT for high-performance data processing and visualization.

Primary Use Cases

Relationship Visualization

Connect the dots between IPs, domains, and emails using an interactive graph engine for deep investigation analysis.

Digital Reconnaissance

Aggregate intelligence from multiple public sources to build comprehensive digital footprints of entities.

Developer Guide

1. Fork & Clone

Create your own copy of the repository and clone it to your local machine.

git clone https://github.com/YOUR-USERNAME/ReConan.git

2. Configure Environment

Copy .env.example to .env and fill in your SQL Server credentials.

Copy-Item .env.example .env

3. Build & Run

Launch the application using Maven and the JavaFX plugin:

mvn javafx:run

4. Contribution

Ensure your changes follow the modular style and submit a Pull Request with a detailed description.
